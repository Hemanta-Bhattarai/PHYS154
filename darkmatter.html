How to use it

  1. Start with the slider at 0. The white curve shows how fast stars would orbit if the galaxy contained only the stars and gas we can see. Notice where it misses the data.
  2. Slowly add dark matter. Watch which part of the curve changes most: the inner galaxy or the outer edge.
  3. Stop when the white curve passes through as many error bars as possible and the match meter reads “great fit.” Record the amount of dark matter.
  4. Press Try a mystery galaxy and repeat. Each mystery galaxy has a different amount of dark matter for you to find.

The physics in one line

A star in a circular orbit needs gravity to pull it around. More mass inside the orbit means a stronger pull and a faster orbit:

speed² = G × (mass inside the orbit) ÷ distance

If almost all the mass were in the bright center, speeds would drop with distance, the way outer planets orbit the Sun more slowly. Instead the speeds stay high far past where the light fades, so the mass keeps growing where we see almost nothing. That unseen mass is dark matter.
